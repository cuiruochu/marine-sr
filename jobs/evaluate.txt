# 评估实验队列
# 规则：
# 1. 每行一条完整命令，供 scripts/run_queue.py 顺序执行
# 2. 训练模型统一使用各组合当前存在的 last.pth 做评估；bicubic 基线不加载检查点
# 3. 显式覆盖测试集 lr/hr 路径到 ../dataset/test
# 4. wind 当前无 mask；mwp/swh/mwd 使用各自 x2/x4 目录下的 mask.npy
# 5. 已开启 evaluate.save_results=true，结果默认写入 ./results/<model>/<dataset>/x{scale}
# 6. 当前共包含 80 个评估任务：72 个训练模型任务 + 8 个 bicubic 基线任务
#
# 用法示例：
# uv run python scripts/run_queue.py --queue jobs/evaluate.txt
