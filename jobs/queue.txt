# 训练实验队列模板
# 单模型拆分文件见: jobs/queue_*.txt
# 规则：
# 1. 每行一条完整命令
# 2. 以 # 开头的行为注释
# 3. 优先使用 configs/<dataset>/train_x{scale}.yaml 提供数据集、upscale、data_norm、路径与默认训练参数
# 4. 命令行只覆盖少量实验变量，例如 models、resume.checkpoint，必要时也可以临时覆盖 models.in_dim 或 train.lr
#
# 目录约定：
# - wind: configs/wind/train_x2.yaml, configs/wind/train_x4.yaml
# - mwp:  configs/mwp/train_x2.yaml,  configs/mwp/train_x4.yaml
# - swh:  configs/swh/train_x2.yaml,  configs/swh/train_x4.yaml
# - mwd:  configs/mwd/train_x2.yaml,  configs/mwd/train_x4.yaml
#
# 示例：
# ["uv", "run", "python", "scripts/train.py", "--config-name", "wind/train_x2", "models=rcan"]
# ["uv", "run", "python", "scripts/train.py", "--config-name", "mwd/train_x4", "models=swinir", "resume.checkpoint='checkpoints/swinir/mwd/x4/best.pth'"]
# ["uv", "run", "python", "scripts/train.py", "--config-name", "wind/train_x2", "models=edsr", "train.lr=1e-4"]
